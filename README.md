# BINGO Plus! - EXACT 8

เกมบิงโกรายชื่อออนไลน์: ผู้เล่นสแกน QR → ใส่ชื่อ → เลือกชื่อเพื่อนกลุ่มละ 5 คนลงตาราง 5×5 → ทีมงานสุ่มชื่อ → ใครได้ 5 ช่องเรียงกัน (แนวนอน / แนวตั้ง / แนวทแยง) ชนะ

## หน้าเว็บ

| ลิงก์ | ใช้ทำอะไร |
|---|---|
| `/` | หน้าผู้เล่น (มือถือ) — ลิงก์นี้คือ QR code ที่ให้สแกน |
| `/screen` | จอใหญ่ในงาน — QR สำหรับสแกน, หมุนสุ่มชื่อพร้อมเสียงอ่านชื่อ, รายชื่อ "ลุ้น! อีก 1 ชื่อ" และผู้ชนะ BINGO กด **Space** หรือปุ่มเพื่อสุ่ม |
| `/admin` | ทีมงาน — สุ่มชื่อ, ยกเลิกชื่อล่าสุด, ดูการ์ดผู้เล่น, ลบผู้เล่น, เปิด/ปิดรับการ์ด, เริ่มรอบใหม่ |

รายชื่อ "อีก 1 ชื่อ" และผู้ชนะบนจอใหญ่ ระบบคำนวณเองจากการ์ดที่ผู้เล่นกด OK แล้วเทียบกับชื่อที่สุ่มออก (แม่นยำแม้ผู้เล่นลืมแตะ)
รายชื่อทั้ง 76 ท่านอยู่ที่ `src/members.js`

## ตั้งค่าครั้งแรก

### 1) Firebase (ฐานข้อมูล real-time ฟรี)

1. เข้า https://console.firebase.google.com → **Create a project** (ตั้งชื่ออะไรก็ได้ เช่น `exact-8-bingo`, ปิด Google Analytics ได้)
2. เมนูซ้าย **Build → Realtime Database → Create Database** → เลือก location **Singapore (asia-southeast1)** → เลือก **Start in test mode** → Enable
3. แท็บ **Rules** → ลบของเดิม วางเนื้อหาจากไฟล์ `database.rules.json` → **Publish**
4. กลับหน้า Project Overview → กดไอคอน **`</>` (Web)** → ตั้งชื่อแอป → Register app
5. คัดลอกค่า `firebaseConfig` ที่ขึ้นมา (ต้องมี `databaseURL`) ไปวางใน `src/firebaseConfig.js`

ถ้ายังไม่ใส่ config เว็บจะทำงานใน "โหมดทดสอบ" (ข้อมูลอยู่ในเบราว์เซอร์เครื่องเดียว เปิดหลายแท็บลองเล่นได้)

### 2) Vercel

1. https://vercel.com/new → **Import** repo `exact-8-bingo`
2. Framework จะขึ้นเป็น **Vite** อัตโนมัติ → กด **Deploy**
3. ได้ลิงก์ เช่น `https://exact-8-bingo.vercel.app` — QR code บนหน้า `/screen` จะสร้างจากลิงก์นี้ให้เอง

## วันงาน

1. เปิด `/screen` บนคอมที่ต่อโปรเจกเตอร์ → กด **"🔊 คลิกเพื่อเปิดเสียง"** (เบราว์เซอร์บังคับให้คลิกก่อนถึงจะมีเสียง)
2. ให้ผู้เล่นสแกน QR บนจอ ใส่ชื่อ เลือกชื่อลงตาราง (มีปุ่ม 🎲 สุ่มเติมช่องที่เหลือ) แล้วกด OK
3. ดูจำนวน "ผู้เล่นพร้อม" บนจอ แล้วกด **Space** เพื่อสุ่มชื่อ
4. ผู้เล่นแตะชื่อที่ถูกเรียกบนการ์ด ใครได้ 5 ช่องเรียงกันจะขึ้น BINGO! บนจอใหญ่ทันที
5. เล่นรอบต่อไป: `/admin` → "เล่นรอบใหม่ (ใช้การ์ดเดิม)" หรือ "ล้างทั้งหมด" ให้เลือกการ์ดใหม่

## ไฟล์รายชื่อเบอร์โทรทั้งรุ่น (import เข้ามือถือ iOS + Android)

ทำไฟล์ `.vcf` (vCard) **ไฟล์เดียว** ที่มีทุกคนอยู่ข้างใน ส่งเข้ากลุ่ม LINE แล้วแต่ละคนกด import ครั้งเดียวได้ครบทั้งรุ่น

1. เก็บข้อมูลใน Google Sheets / Excel ตามหัวตารางใน `contacts/contacts.example.csv`
   (`ชื่อเล่น, ชื่อ, นามสกุล, เบอร์โทร, กลุ่ม, อีเมล, หมายเหตุ` — มีหลายเบอร์ให้คั่นด้วย `/`)
2. Download เป็น CSV → บันทึกเป็น `contacts/contacts.csv`
3. รัน `npm run contacts` → ได้ไฟล์ `contacts/EXACT8-contacts.vcf`
   (สคริปต์จะแปลงเบอร์เป็น +66 ให้ และเตือนแถวที่ไม่มีเบอร์ / เบอร์ผิด)
4. ส่งไฟล์ `.vcf` ให้ทุกคน

ชื่อในมือถือจะขึ้นเป็น `EXACT8 พี่คิตตี้ ชื่อจริง นามสกุล` — พิมพ์ค้น "EXACT8" เจอเพื่อนทั้งรุ่น

**iPhone:** แตะไฟล์ → ปุ่มแชร์ → **รายชื่อ (Contacts)** → **เพิ่มรายชื่อทั้งหมด N รายการ**
(ถ้าเปิดใน LINE ไม่ขึ้น ให้ "บันทึกลงไฟล์ (Files)" ก่อน แล้วเปิดจากแอป Files หรือส่งทาง AirDrop / อีเมล)

**Android:** แตะไฟล์ → เปิดด้วย **Contacts / รายชื่อติดต่อ** → นำเข้า
หรือแอป Google Contacts → **แก้ไขและจัดการ → นำเข้าจากไฟล์** · Samsung: รายชื่อ → **จัดการรายชื่อ → นำเข้า**

> ไฟล์ CSV และ `.vcf` ที่มีเบอร์จริงถูกตั้งไม่ให้ขึ้น git (`.gitignore`) — อย่าวางไว้ในโฟลเดอร์ `public/` เพราะใครมีลิงก์ก็โหลดได้
